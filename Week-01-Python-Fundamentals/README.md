# Week 1 – Python Fundamentals

## Overview

During the first week of the internship, I focused on strengthening my Python programming skills. The work covered Python syntax, control flow, built-in data structures, functions, object-oriented programming, file handling, and exception handling.

## Files Included

1. `python_fundamentals.py`
   - Variables and data types
   - Type casting
   - Operators
   - Strings
   - Conditional statements
   - Loops
   - User input
   - Comprehensions

2. `data_structures_and_functions.py`
   - Lists, tuples, sets, and dictionaries
   - Functions
   - Default and keyword arguments
   - `*args` and `**kwargs`
   - Lambda functions
   - `map()`, `filter()`, `zip()`, and `enumerate()`
   - Modules and reusable logic

3. `oop_file_handling_exceptions.py`
   - Classes and objects
   - Constructors
   - Encapsulation
   - Inheritance
   - Polymorphism
   - File handling
   - JSON handling
   - Exception handling
   - Custom exceptions
